# Dewmi — Birthday Surprise 💗

A romantic, animated birthday website made with Next.js and your six supplied photos.

## Run locally
1. Install Node.js 20 or newer.
2. Open this project folder in VS Code.
3. Run `npm install`, then `npm run dev`.
4. Open http://localhost:3000.

## Publish free with GitHub Pages
1. Create a **public** repository on GitHub (for example, `dewmi-birthday`).
2. Extract this ZIP file.
3. Upload the **contents inside** the `birthday-surprise` folder to the root of the repository. Include the hidden `.github` folder.
4. Commit the files to the `main` branch.
5. In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions**.
6. Open **Actions** and wait for “Deploy birthday surprise to GitHub Pages” to finish successfully.
7. Your site will be at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

New commits to `main` automatically redeploy the site. No database, paid hosting, or server is needed.

## Included
Dewmi's name, all six supplied photos, animated floating hearts, responsive photo gallery with tap-to-zoom, birthday wishes, an interactive envelope letter, and a final surprise message.
